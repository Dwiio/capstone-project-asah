# Data Dictionary

| Field | Type | Required | Meaning | Privacy/notes |
|---|---|---|---|---|
| member_code | varchar(24) | yes | Unique membership identifier | Generated by system; avoid exposing in public pages |
| full_name | varchar(100) | yes | Member name | Personal data; admin only |
| phone | varchar(20) | yes | Member contact number | Personal data; admin only |
| email | varchar(190) | no | Member email | Personal data; collect only if needed |
| package_id | bigint | yes | Membership package relation | FK to membership_packages |
| start_date | date | yes | Membership start | Used in validity calculation |
| end_date | date | yes | Membership end | `expired` if earlier than current date |
| administrative_status | enum | yes | `active` / `inactive` administrative state | Separate from calculated expiry |
| notes | varchar(500) | no | Admin note | Do not store sensitive unnecessary data |
| deleted_at | timestamp | no | Soft deletion time | Null means visible record |

Demo data is synthetic. No real member personal data is included.
