# User Guide

## Public website

1. Open the site URL.
2. Use navigation to read About, Facilities, Membership, Gallery, and Contact sections.
3. Select the moon/sun icon to switch light/dark theme; the preference is stored in the browser.
4. Open “Ask us” to ask common membership questions. Chatbot replies are limited to confirmed information; unknown questions are referred to the gym administrator.
5. Select Admin Login in the top-right corner for administrator access.

## Administrator

1. Sign in using the administrator account supplied by the system owner.
2. Overview displays total, active, expired, and near-expiry membership counts.
3. Membership menu: search by name, member ID, or phone; filter by status/package; add, edit, and archive members.
4. Packages menu: create/edit package duration and description. Set actual prices only after confirmation from the UMKM owner.
5. Analytics menu displays member totals, package distribution, and six-month registration trend from records stored by this app.
6. Activity Log displays recent admin events.
7. Sign out using the sidebar.

## Member form rules

- Name required.
- Phone must be 8–20 characters matching a phone-number pattern.
- Package must be active.
- Start/end dates required; end date must not precede start date.
- Archive is soft deletion; it removes the record from the active list without permanently deleting it.
